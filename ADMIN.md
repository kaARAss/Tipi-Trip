# Админ-панель «Типи-Трип»

## Адрес и первая настройка

Откройте `/admin.html` или `/admin/`. Старый адрес `/#/admin` перенаправляет в новую панель.

При первой настройке задайте логин, длинный уникальный пароль (не менее 12 символов) и отдельный fine-grained GitHub token:

- Resource owner: `kaARAss`.
- Repository access: только `Tipi-Trip`.
- Repository permissions → Contents: Read and write. Metadata: Read (автоматически).
- Ограниченный срок действия; не используйте токен другого проекта.

Админка проверит доступ на запись и сохранит **только зашифрованный** `admin-vault.json`. Пароль локально выводит ключ PBKDF2-SHA256 (600 000 итераций), шифрование AES-256-GCM со случайными солью/nonce и привязкой к этому репозиторию. Пароль по сети не отправляется. Расшифрованный токен остаётся только в памяти вкладки и отправляется только `api.github.com`. После перезагрузки требуется новый вход. Не вставляйте пароль или токен в файлы, чат, localStorage или `.env` в публичном репозитории.

**Ограничение статической авторизации:** это не серверная сессия. Публичный зашифрованный файл допускает офлайн-подбор пароля без ограничения попыток. Компрометация пароля раскрывает токен. Нужны длинный уникальный пароль, минимальные права и срок токена. При утечке замените оба и отдельно отзовите старый токен в GitHub: старые зашифрованные версии остаются в Git-истории.

## Работа

- Главная: четыре текстовых экрана, 12 фото анимации, фоновое видео и постер.
- Карточки услуг: отдельные превью, текст, цены, полное описание, фото/видео внутри. Материалы можно добавлять, удалять и менять порядок.
- Полезная информация: все раскрывающиеся блоки, списки и эмодзи.
- Контакты и меню: телефоны, ссылки, адреса и карта.
- Фоны и медиа: фон, логотип, карта территории и дополнительные сцены.
- Остальные тексты: кнопки и подписи; для отсутствующего текста откройте предпросмотр → «Выбрать на сайте» и нажмите на него.

«Положение в рамке»: перетаскивание, горизонталь/вертикаль, масштаб 1–3×, отдельные значения для телефона и ПК. Исходный файл не обрезается. Кадрирование фото анимации применяется и к WebGL-атласу. Изменение текстов/кадрирования передаётся в предпросмотр сразу. После замены файлов анимации обновите предпросмотр; у материалов внутри карточек данные обновляются при загрузке.

Изображения JPG/PNG/WebP/AVIF преобразуются локально в WebP до 2400 px; HEIC конвертируется локальной копией CSP-сборки heic-to 1.6.7 в Web Worker. Фото не отправляется сторонним сервисам. GIF сохраняется без потери анимации. Видео MP4/WebM/MOV до 95 МБ; рекомендуется MP4/H.264 с AAC, совместимость проверяется браузером. Крупные ролики предварительно сожмите. Новые файлы получают уникальные пути `media/uploads/`, поэтому старый кэш не скрывает замену.

## Сохранение и публикация

Черновик автоматически сохраняется в IndexedDB этого браузера вместе с новыми файлами, **без пароля и токена**. Кнопка «Сохранить черновик» делает это явно. На другом устройстве этот черновик недоступен.

«Опубликовать» отправляет `site-content.json` и используемые новые медиа **одним Git-коммитом** в `main`, без перезаписи кода сайта. Обновление ветки выполняется с `force:false`. Перед записью проверяется SHA контента: чужие изменения блокируют публикацию, а не затираются. При ошибке черновик и выбранные файлы остаются для повторной попытки.

После коммита GitHub Pages публикует сайт. Панель отдельно проверяет появление новой ревизии по публичному адресу; коммит не выдаётся за уже завершённую сборку. Статус сборки — в Actions репозитория.

## Источник данных

`site-content.json` — единый источник текстов, галерей, фона и кадрирования. `assets/content-loader.js` загружает его перед React. Старый localStorage-контент публичными страницами не применяется. `assets/site-cms-entry.js` содержит минимальные привязки исходной сборки; исходные страницы, анимация и оформление сохранены.

Панель не публикует свой код или HTML при загрузке медиа. Тексты выводятся как текст, не через `innerHTML`. SVG/HTML/JS не принимаются как новые файлы. Предпросмотр принимает команды только от родительской админки того же origin и только в специально открытом режиме. CSP админки ограничивает отправку данных GitHub API.

## Проверки

Требуются Python, Playwright и Chromium:

```bash
python tests/test_mobile_scrollbar.py
python tests/test_admin_cms.py
python tests/test_cms_public.py
python tests/test_media_framing.py
```

`test_admin_cms.py` полностью подменяет GitHub API. Настоящий токен не используется и настоящий репозиторий не изменяется. Проверяются шифрование первой настройки, живой предпросмотр, кадрирование, загрузка фото/видео, черновики, ошибки публикации, повтор, контроль конфликтов, мобильный и настольный интерфейсы.

## Смена доступа и восстановление

Раздел «Доступ и публикация» позволяет зашифровать новый токен новым паролем. Старый токен отзовите отдельно. Если пароль забыт, владелец репозитория может удалить `admin-vault.json`, отозвать старый токен и пройти первую настройку с новым. Только владельцы с правом записи могут сохранить новую конфигурацию.

Для отката используйте `git revert` нужного коммита, без force-push. Контент и медиа публикуются вместе, что позволяет откатить соответствующую публикацию целиком. Перед обновлением кода сохраните текущую ревизию и проверьте сайт на телефоне и ПК.

## Точность кадрирования

Редактор рисует выбранный кадр непосредственно в canvas и использует тот же расчёт окна исходника, что и WebGL-лента. Размеры обычных рамок считываются из настоящей страницы сайта в изолированном предпросмотре соответствующей ширины. Редактор показывает уменьшенную копию рамки без изменения пропорций. Для 3D-ленты сохранены пропорции сектора, но перспектива и видимый размер меняются при прокрутке. Перетаскивание и ползунки положения никогда не меняют масштаб. Приближение задаётся нижним ползунком или дискретными шагами колеса над кадром (1–3×). Плавные пиксельные события прокрутки и жесты pinch не используются для приближения. Если для сдвига нет запаса, увеличьте масштаб вручную; исходный файл не изменяется.
